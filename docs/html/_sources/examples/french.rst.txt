.. admonition:: Summary

    This is a source transformation that allows one
    to use French equivalent keywords to the existing ones.
    It also demonstrates how to make use of a different file extension (``.pyfr``),
    loading such files as if they were regular Python files.

   `Source code <https://github.com/aroberge/ideas/blob/master/ideas/examples/french.py>`_
